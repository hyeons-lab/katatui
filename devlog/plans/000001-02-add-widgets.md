# Plan: Add Remaining ratatui Widgets

## Thinking

katatui currently wraps three ratatui widgets: Block, Paragraph, List. The ratatui widget
ecosystem has seven more practical widgets we should expose via the FFI layer: Clear, Gauge,
LineGauge, Sparkline, BarChart, Tabs, and Table.

Two codegen bugs block the new widgets:

1. **Multi-word group detection**: `CFunction.group` splits on the first underscore after
   `katatui_`, so `katatui_line_gauge_*` → group `line` instead of `line_gauge`. The fix
   derives snake_case prefixes from the `opaqueTypes` registry and matches each function to the
   longest matching prefix.

2. **Missing uint64_t mapping**: `WrapperEmitter.cTypeToKotlin` falls through to `Any` for
   `uint64_t` (used by Sparkline data values). Fix by adding an explicit `ULong` case.

Each new widget follows the three-layer pattern:
- Rust FFI: opaque struct + `build_*()` + `#[no_mangle] extern "C"` functions
- katatui.h: auto-regenerated by cbindgen
- Kotlin: codegen produces wrapper class; hand-written extensions for complex types

Canvas (closure-based) and Chart (complex axes/datasets) are deliberately excluded.
