## Thinking

The sample app has 7 tabs (Dashboard, Chart, Canvas, Scrollbar, Branding, Widgets, Image). This plan adds an 8th tab that mimics the Katatui Code terminal UI, showcasing:

- A scrollable chat history with `❯` / `◆` prefixes and the logo at the top
- A `/`-triggered command picker with TAB-cycle completion
- A status bar styled like a shell prompt (cwd · branch · model)
- Clean MVI architecture: immutable `KatatuiCodeState`, sealed `KatatuiCodeIntent`, pure reducer

Two new key codes are needed at the FFI layer: Backspace (0x08) and Tab (0x09). The existing
`katatui_event_read_key_code` signature is unchanged — only two new arms are added to the Rust
`match`.

The tab stays on the existing `feat/initial-project-v2` branch (same PR #1).
